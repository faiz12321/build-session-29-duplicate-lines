How to find repeated lines in a text file

Short answer

An exported list can hide copies: the same entry typed twice, or a blank gap repeated over and over. This lesson builds a small read-only Python tool that reads a text file and shows which lines appear more than once, most repeated first, with counts. A duplicate means the exact same text, so letter case and spaces count. The tool has no code that changes, moves or deletes anything.

Common mistakes

  1. Re-reporting a line once per copy. If Milk appears three times, printing it three times tells you nothing new and makes the report longer than the file. Count first, then report each repeated line once.
  2. Assuming near-duplicates count. The match is exact text: "Milk" and "milk" are different lines, and so are "Milk" and "Milk ". Tidy formatting first if you want those grouped.
  3. Treating repeats as errors. A repeated line can be fine: blank lines separate sections on purpose. The tool shows counts; which copies matter is your call.

Frequently asked questions

Why does the final version read the file only once?

Counting with a dictionary means one pass: each line is looked up and its count grows by one. The first version instead compared every line with every line, which gets slow quickly on a big file.

Why do letter case and spaces matter?

The tool matches exact text, because silently merging "Milk" and "milk" could hide a real difference. What counts as the same is a choice, and this lesson says its choice out loud.

Will it change my file?

No. It only reads. One test checks that the source has no code that writes, and another checks that a file, including its size and changed time, is exactly the same after a run.

Can it fix the duplicates for me?

No, on purpose. Removing a line changes your data, and which copy to keep is a judgment the tool cannot make. It only shows what repeats and how often.

What file types can it read?

Plain text saved as UTF-8. Anything else stops with a clear message instead of guessing. Word documents and PDFs are not plain text.
